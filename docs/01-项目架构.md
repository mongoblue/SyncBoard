# SyncBoard 项目架构文档

## 1. 项目概述

SyncBoard 是一个现代化的**项目协作看板系统**，采用前后端分离架构，支持实时同步、AI智能助手、质量中心等高级功能。

### 1.1 核心特性

- **看板管理**：多项目支持、拖拽排序、任务卡片
- **实时协作**：WebSocket 实时同步、在线状态显示
- **全文搜索**：基于 Elasticsearch 的任务搜索
- **AI助手**：RAG 智能问答、上下文感知
- **质量中心**：API测试、UI自动化测试、性能测试

## 7. 数据流图

### 7.1 看板操作流程

```
用户操作 (拖拽任务)
    │
    ▼
前端: vuedraggable 触发 @change
    │
    ▼
前端: 调用 updateTask API
    │
    ▼
后端: TaskViewSet.update()
    │
    ▼
后端: 更新数据库 + 发送WebSocket消息
    │
    ▼
后端: channel_layer.group_send()
    │
    ▼
Redis: 广播消息到所有订阅者
    │
    ▼
前端: BoardConsumer 接收消息
    │
    ▼
前端: fetchColumns() 刷新看板
```

### 7.2 搜索操作流程

```
用户输入关键词
    │
    ▼
前端: 调用 /api/tasks/search/?q=xxx
    │
    ▼
后端: SearchView
    │
    ▼
Haystack: 构建ES查询
    │
    ▼
Elasticsearch: 执行搜索
    │
    ▼
后端: 返回高亮结果
    │
    ▼
前端: 展示搜索结果
```

### 7.3 AI问答流程

```
用户提问
    │
    ▼
前端: 发送问题到 /api/chat/
    │
    ▼
后端: 从ES检索相关任务
    │
    ▼
后端: 格式化任务上下文
    │
    ▼
后端: 调用 DeepSeek API
    │
    ▼
DeepSeek: 生成回答
    │
    ▼
后端: 返回答案
    │
    ▼
前端: 展示AI回复
```
