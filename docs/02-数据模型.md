## 2. room应用 - 核心业务模型

### 2.1 UserProfile (用户资料)

```python
class UserProfile(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE, related_name='profile')
    avatar = models.ImageField(upload_to=get_avatar_upload_path, blank=True, null=True)
```

**设计说明：**
- 扩展 Django 内置 User 模型
- 使用 `OneToOneField` 建立一对一关系
- 头像使用动态路径存储：`avatars/user_{user_id}/{filename}`
- 通过信号自动创建：`post_save` 信号监听 User 创建

**使用示例：**
```python
# 获取用户头像
user.profile.avatar.url

# 自动创建信号
@receiver(post_save, sender=User)
def create_user_profile(sender, instance, created, **kwargs):
    if created:
        UserProfile.objects.create(user=instance)
```

### 2.2 Project (项目)

```python
class Project(models.Model):
    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    name = models.CharField(max_length=255)
    owner = models.ForeignKey(User, on_delete=models.CASCADE, related_name='owned_projects')
    members = models.ManyToManyField(User, related_name='joined_projects', blank=True)
    created_at = models.DateTimeField(auto_now_add=True)
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUIDField | 主键，自动生成，不可编辑 |
| name | CharField | 项目名称，最大255字符 |
| owner | ForeignKey | 项目所有者，级联删除 |
| members | ManyToManyField | 项目成员，多对多关系 |
| created_at | DateTimeField | 创建时间，自动添加 |

**设计亮点：**
- 使用 `UUID` 作为主键，避免序列攻击，支持分布式部署
- `owner` 和 `members` 分离，明确权限边界
- `related_name` 便于反向查询

**查询示例：**
```python
# 获取用户创建的项目
user.owned_projects.all()

# 获取用户参与的项目
user.joined_projects.all()

# 获取项目的所有成员
project.members.all()
```

### 2.3 Column (看板列)

```python
class Column(models.Model):
    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    project = models.ForeignKey(Project, on_delete=models.CASCADE, related_name='columns')
    title = models.CharField(max_length=255)
    position = models.FloatField(default=65535)

    class Meta:
        ordering = ['position']
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUIDField | 主键 |
| project | ForeignKey | 所属项目，级联删除 |
| title | CharField | 列标题（如：To Do, In Progress, Done） |
| position | FloatField | 排序位置，默认65535 |

**排序算法详解：**

```python
# 位置计算策略
# 1. 默认位置：65535（中间值，便于前后插入）
# 2. 列间拖拽：(prev_position + next_position) / 2
# 3. 拖到列首：min_position - 65535
# 4. 拖到列尾：max_position + 65535

# 示例：在位置 10000 和 20000 之间插入新列
new_position = (10000 + 20000) / 2  # = 15000

# 示例：插入到最前面
new_position = min_position - 65535
```

**优势：**
- 使用浮点数支持无限级排序
- 避免频繁更新所有记录的位置
- 支持拖拽排序的平滑体验

### 2.4 Task (任务卡片)

```python
class Task(models.Model):
    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    column = models.ForeignKey(Column, on_delete=models.CASCADE, related_name='tasks')
    title = models.CharField(max_length=255)
    content = models.TextField(blank=True)
    position = models.FloatField(default=65535)
    tags = models.ManyToManyField(Tag, blank=True, related_name='tasks')
    assignee = models.ForeignKey(User, on_delete=models.SET_NULL, null=True, blank=True, related_name='tasks')

    class Meta:
        ordering = ['position']
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUIDField | 主键 |
| column | ForeignKey | 所属列，级联删除 |
| title | CharField | 任务标题 |
| content | TextField | 任务内容，可为空 |
| position | FloatField | 在列中的排序位置 |
| tags | ManyToManyField | 任务标签 |
| assignee | ForeignKey | 负责人，删除时设为NULL |

**级联策略对比：**

| 关系 | 级联策略 | 说明 |
|------|----------|------|
| column | CASCADE | 列删除时，任务也删除 |
| assignee | SET_NULL | 用户删除时，任务保留，负责人设为NULL |
| tags | - | 多对多，标签删除时自动解除关联 |

**查询示例：**
```python
# 获取列的所有任务（已按position排序）
column.tasks.all()

# 获取用户的所有任务
user.tasks.all()

# 获取带有特定标签的任务
tag.tasks.all()

# 跨列查询（获取项目下所有任务）
Task.objects.filter(column__project=project)
```

```python
class Notification(models.Model):
    NOTIFICATION_TYPES = [
        ('task', '任务'),
        ('member', '成员'),
        ('system', '系统'),
        ('success', '成功'),
        ('warning', '警告'),
    ]

    user = models.ForeignKey(User, on_delete=models.CASCADE, related_name='notifications')
    title = models.CharField(max_length=255)
    message = models.TextField()
    type = models.CharField(max_length=20, choices=NOTIFICATION_TYPES, default='system')
    is_read = models.BooleanField(default=False)
    project = models.ForeignKey(Project, on_delete=models.CASCADE, null=True, blank=True, related_name='notifications')
    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ['-created_at']
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| user | ForeignKey | 接收通知的用户 |
| title | CharField | 通知标题 |
| message | TextField | 通知内容 |
| type | CharField | 通知类型（枚举） |
| is_read | BooleanField | 是否已读 |
| project | ForeignKey | 关联项目（可选） |
| created_at | DateTimeField | 创建时间 |

**通知类型使用场景：**

| 类型 | 场景 |
|------|------|
| task | 任务被创建、更新、删除 |
| member | 成员加入/离开项目 |
| system | 系统公告 |
| success | 操作成功提示 |

```python
class ApiTestCase(models.Model):
    HTTP_METHODS = [
        ('GET', 'GET'),
        ('POST', 'POST'),
        ('PUT', 'PUT'),
        ('DELETE', 'DELETE'),
        ('PATCH', 'PATCH'),
        ('HEAD', 'HEAD'),
        ('OPTIONS', 'OPTIONS'),
    ]

    project = models.ForeignKey(Project, on_delete=models.CASCADE, related_name='api_test_cases')
    name = models.CharField(max_length=200, verbose_name='测试用例名称')
    url = models.CharField(max_length=1000, verbose_name='请求地址')
    method = models.CharField(max_length=10, choices=HTTP_METHODS, default='GET')
    headers = models.JSONField(default=dict, blank=True, verbose_name='请求头')
```

### 3.4 TestResult (统一测试结果)

```python
class TestResult(models.Model):
    TEST_TYPE_CHOICES = [
        ('api', '接口测试'),
        ('ui', 'UI测试'),
        ('performance', '性能测试'),
        ('regression', '回归测试'),
    ]

    STATUS_CHOICES = [
        ('passed', '通过'),
        ('failed', '失败'),
        ('error', '错误'),
        ('running', '运行中'),
        ('pending', '待执行'),
    ]

    id = models.AutoField(primary_key=True)
    test_type = models.CharField(max_length=20, choices=TEST_TYPE_CHOICES)
    name = models.CharField(max_length=200, verbose_name='测试名称')

    project = models.ForeignKey(Project, on_delete=models.CASCADE, related_name='test_results', null=True, blank=True)
    api_test_case = models.ForeignKey(ApiTestCase, on_delete=models.SET_NULL, null=True, blank=True, related_name='test_results')
    ui_test_case = models.ForeignKey(UiTestCase, on_delete=models.SET_NULL, null=True, blank=True, related_name='test_results')

    status = models.CharField(max_length=20, choices=STATUS_CHOICES, default='pending')
    executed_by = models.ForeignKey(User, on_delete=models.SET_NULL, null=True, related_name='executed_tests')
    started_at = models.DateTimeField(null=True, blank=True)
    completed_at = models.DateTimeField(null=True, blank=True)
    duration_ms = models.IntegerField(null=True, blank=True)

    test_params = models.JSONField(default=dict, blank=True, null=True)
    test_steps = models.JSONField(default=list, blank=True, null=True)
    expected_result = models.TextField(blank=True, null=True)
    actual_result = models.TextField(blank=True, null=True)
    error_message = models.TextField(blank=True, null=True)
    test_log = models.TextField(blank=True, null=True)

    response_time_ms = models.IntegerField(null=True, blank=True)
    throughput = models.FloatField(null=True, blank=True)
    error_rate = models.FloatField(null=True, blank=True)
    concurrent_users = models.IntegerField(null=True, blank=True)

    test_environment = models.CharField(max_length=200, blank=True)
    browser_info = models.CharField(max_length=200, blank=True)
    user_agent = models.TextField(blank=True)

    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        indexes = [
            models.Index(fields=['test_type', 'status']),
            models.Index(fields=['project', 'created_at']),
            models.Index(fields=['executed_by', 'created_at']),
        ]
```

**设计说明：**
- 统一的测试结果模型，支持多种测试类型
- 通过 `api_test_case` 和 `ui_test_case` 关联到具体用例
- 性能指标字段（response_time_ms, throughput, error_rate）专用于性能测试
- 数据库索引优化常用查询场景

## 6. 模型设计最佳实践

### 6.1 主键选择

| 类型 | 使用场景 | 本项目使用 |
|------|----------|-----------|
| AutoField | 内部系统、简单应用 | - |
| UUIDField | 分布式系统、对外暴露 | Project, Column, Task |
| 自然键 | 有明确唯一标识的业务 | - |

**UUID优势：**
- 支持分布式部署，避免ID冲突
- 不可猜测，增强安全性
- 支持离线创建记录

### 6.2 级联策略选择

| 策略 | 使用场景 | 本项目示例 |
|------|----------|-----------|
| CASCADE | 强关联，父删除子必须删除 | Column→Task |
| PROTECT | 防止误删除 | - |
| SET_NULL | 子可独立存在 | Task→assignee |
| SET_DEFAULT | 有默认值的场景 | - |
| DO_NOTHING | 数据库层面处理 | - |

### 6.3 JSONField 使用场景

| 场景 | 示例 | 原因 |
|------|------|------|
| 灵活配置 | headers, body | 结构不固定 |
| 列表数据 | steps, assertions | 无需单独建表 |
| 动态属性 | test_params | 不同测试类型参数不同 |

## 8. 常用查询模式

### 8.1 看板相关查询

```python
# 获取项目的完整看板数据（含列和任务）
project = Project.objects.prefetch_related(
    'columns__tasks__tags',
    'columns__tasks__assignee'
).get(id=project_id)

for column in project.columns.all():
    print(f"列: {column.title}")
    for task in column.tasks.all():
        print(f"  - {task.title} ({task.assignee.username if task.assignee else '未指派'})")

# 获取用户的所有任务
user_tasks = Task.objects.filter(
    assignee=user
).select_related('column__project').prefetch_related('tags')

# 获取带特定标签的任务
tagged_tasks = Task.objects.filter(
    tags__name='紧急'
).distinct()
```

### 8.2 测试相关查询

```python
# 获取项目的最新测试结果
latest_results = TestResult.objects.filter(
    project=project
).order_by('-created_at')[:10]

# 获取失败的API测试
failed_api_tests = TestResult.objects.filter(
    test_type='api',
    status='failed'
).select_related('api_test_case')

# 统计测试通过率
total = TestResult.objects.filter(project=project).count()
passed = TestResult.objects.filter(project=project, status='passed').count()
pass_rate = passed / total * 100 if total > 0 else 0
```

### 8.3 通知相关查询

```python
# 获取用户的未读通知
unread_notifications = Notification.objects.filter(
    user=user,
    is_read=False
).order_by('-created_at')

# 标记所有通知为已读
Notification.objects.filter(user=user, is_read=False).update(is_read=True)
```
